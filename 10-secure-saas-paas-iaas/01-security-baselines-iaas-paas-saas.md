# Security Baselines for IaaS, PaaS and SaaS

- [Link](https://learn.microsoft.com/en-us/security/benchmark/azure/)

- Cloud Security Baselines
  - Microsoft-recommended security configurations and controls that help organizations secure Azure services, reduce vulnerabilities, and maintain consistent security standards based on the Microsoft Cloud Security Benchmark (MCSB).
  
- Key Capabilities
  - Standardized Security Controls
    - Establish consistent security requirements across Azure resources.
  - Identity & Access Management
    - Recommend least-privilege access, MFA, and privileged access controls.
  - Network Security
    - Define best practices for network isolation, segmentation, and traffic protection.
  - Data Protection and Encryption
    - Recommend encryption, access controls, and secure data handling.
  - Logging & Monitoring
    - Establish recommendations for security monitoring and threat detection.
