# Security Posture with Microsoft Secure Score

- [Link](https://learn.microsoft.com/en-us/defender-xdr/microsoft-secure-score-improvement-actions)

- Microsoft Defender > Secure Score

- Microsoft Secure Score
  - Microsoft Secure Score is a security assessment tool that measures an organization's security posture and provides actionable recommendations to reduce risks and improve security across Microsoft environments.
  
  - Capabilities
    - Security Posture Assessment
      - Measures security effectiveness using a numerical score.
    - Improvement Recommendations
      - Identifies security gaps and suggests corrective actions.
    - Risk Prioritization
      - Helps prioritize security improvements based on potential impact.
    - Progress Tracking
      - Monitors security posture improvements over time.
    - Security Benchmarking
      - Supports comparison against similar organizations.
