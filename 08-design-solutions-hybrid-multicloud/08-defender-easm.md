# Microsoft Defender External Attack Surface Management

- [Link](https://learn.microsoft.com/en-us/azure/external-attack-surface-management/)

- Azure Portal > Microsoft Defender EASM

- Microsoft Defender External Attack Surface Management (EASM)
  - A security solution that continuously discovers, monitors, and assesses an organization's internet-facing assets to identify vulnerabilities, security risks, and unknown exposures from an attacker's perspective.

- Capabilities
  - Asset Discovery
    - Identifies internet-facing assets, including domains, IP addresses, servers, and web applications.
  - Shadow IT Detection
    - Discovers unknown or unmanaged external assets.
  - Vulnerability Identification
    - Detects security weaknesses and potentially exploitable exposures.
  - Continuous Monitoring
    - Tracks changes to an organization's external attack surface.
  - Risk Prioritization
    - Identifies high-risk assets and vulnerabilities requiring attention.
  - Third-Party Visibility
    - Identifies external infrastructure and dependencies.
  - Defender for Cloud Integration
    - Enhances cloud security posture management and attack path analysis. 

- Use Cases
  - Attack Surface Discovery
    - Identify unknown internet-facing resources.
  - Exposure Management
    - Detect exposed services and vulnerable systems.
  - Shadow IT Management
    - Discover unmanaged applications and infrastructure.
  - Security Assessments
    - Evaluate externally visible security weaknesses.
  - Risk Reduction
    - Prioritize remediation of critical external exposures.
