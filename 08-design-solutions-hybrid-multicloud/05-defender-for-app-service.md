# Microsoft Defender for App Service

- [Link](https://learn.microsoft.com/en-us/azure/defender-for-cloud/defender-for-app-service-introduction)

- Azure Portal > Defender for Cloud > Environment Settings > Click on Subscription

- Micrsoft Defender for App Services
  - A cloud workload protection solution within Microsoft Defender for Cloud that provides threat detection, security monitoring, and recommendations for web applications and APIs hosted in Azure App Service.
  
  - Capabilities
    - Threat Detection
      - Identifies malicious activity and attacks targeting web applications.
    - Security Recommendations
      - Identifies misconfigurations and provides guidance to improve security.
    - Application Monitoring
      - Analyzes application requests, responses, and runtime activity for suspicious behavior.
    - Attack Detection
      - Detects reconnaissance, code execution attempts, and other application threats.
    - DNS Protection
      - Identifies dangling DNS configurations that could lead to subdomain takeover.
    - Security Alerts
      - Generates alerts to support investigation and incident response.
    - Native Integration
      - Integrates with Azure App Service without requiring additional agents. 

- Use Cases
  - Web Application Protection 
    - Detect attacks against hosted web applications.
  - API Security Monitoring
    - Identify suspicious activity targeting App Service APIs.
  - Threat Investigation
    - Investigate malicious requests and potentially compromised applications.
  - Security Hardening
    - Identify and remediate insecure App Service configurations.
