# Security Posture with Microsoft Defender for Cloud

- [Link](https://learn.microsoft.com/en-us/azure/defender-for-cloud/concept-cloud-security-posture-management)

- Azure Portal > Defender for Cloud > Security Posture

- Cloud Security Posture Management (CSPM)
  - A core capability of Microsoft Defender for Cloud that continuously assesses cloud environments to identify security risks, misconfigurations, and compliance gaps across Azure, AWS, and Google Cloud.

  - Capabilities
    - Continuous Security Assessment
      - Monitors cloud resources for security weaknesses and misconfigurations.
    - Secure Score
      - Measures security posture and recommends improvements.
    - Risk Prioritization
      - Identifies and prioritizes critical security risks.
    - Compliance Monitoring
      - Evaluates resources against security standards and regulatory requirements.
    - Attack Path Analysis
      - Identifies potential attack paths to critical resources.
    - Vulnerability Assessment
      - Detects vulnerabilities in cloud workloads and configurations.
    - Multicloud Visibility
      - Provides centralized security insights across cloud environments.

- CSPM Plans
  - Foundational CSPM (Free)
    - Provides basic security assessments, Secure Score, and remediation recommendations.
  - Defender CSPM (Paid)
    - Adds advanced capabilities, including attack path analysis, vulnerability scanning, AI security posture management, and risk prioritization.
