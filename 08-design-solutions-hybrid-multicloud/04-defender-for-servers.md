# Microsoft Defender for Servers

- [Link](https://learn.microsoft.com/en-us/azure/defender-for-cloud/defender-for-servers-overview)

- Azure Portal > Defender for Cloud > Environment Settings > Defender Plan Coverage

- Microsoft Defender for Servers
  - Microsoft Defender for Servers is a cloud workload protection solution within Microsoft Defender for Cloud that provides threat detection, vulnerability management, and security posture monitoring for Windows and Linux servers across Azure, AWS, Google Cloud, and on-premises environments.
  
  - Capabilities
    - Threat Detection
      - Identifies malicious activity, suspicious behavior, and potential attacks.
    - Endpoint Protection
      - Integrates with Microsoft Defender for Endpoint for endpoint detection and response (EDR).
    - Vulnerability Management
      - Identifies software vulnerabilities and security weaknesses.
    - Security Posture Management
      - Assesses server configurations and recommends security improvements.
    - Agentless Scanning
      - Detects vulnerabilities, malware, and exposed secrets without installing agents.
    - Just-in-Time (JIT) Access
      - Reduces exposure by restricting management port access.
    - Compliance Monitoring
      - Evaluates server configurations against security standards.

- Defender for Servers Plans
  - Plan 1 (P1)
    - Provides foundational server protection focused on endpoint detection and response.
  - Plan 2 (P2)
    - Includes Plan 1 capabilities plus advanced features such as agentless scanning, JIT access, file integrity monitoring, and additional vulnerability management capabilities.
