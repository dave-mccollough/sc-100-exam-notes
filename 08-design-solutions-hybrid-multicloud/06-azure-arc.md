# Azure Arc

- [Link](https://learn.microsoft.com/en-us/azure/azure-arc/overview)

- Azure Portal > Azure Arc

- Azure Arc
  - Hybrid and multicloud management platform that extends Azure's management, security, and governance capabilities to resources running on-premises, in other cloud providers, and at edge locations
  
    - Capabilities
      - Centralized Management
        - Manage servers, Kubernetes clusters, and databases across multiple environments.
      - Hybrid & Multicloud Support
        - Extend Azure services to AWS, Google Cloud, and on-premises infrastructure.
      - Security Integration
        - Integrate with Microsoft Defender for Cloud for threat detection and security posture management.
      - Policy & Governance
        - Apply Azure Policy, RBAC, and compliance controls across environments.
      - Monitoring & Updates
        - Use Azure Monitor and Azure Update Manager to monitor and maintain resources.
      - Kubernetes Management   
        - Manage Kubernetes clusters and automate configurations using GitOps.
      - Resource Inventory
        - View and organize non-Azure resources through Azure Resource Manager.
      
    - Use Cases
      - Hybrid Cloud Management
        - Manage on-premises and Azure resources through a unified interface.
      - Multicloud Governance
        - Apply consistent security and compliance policies across cloud providers.
      - Server Security
        - Extend Defender for Cloud protection to non-Azure servers.
      - Kubernetes Operations
        - Centrally manage distributed Kubernetes clusters.
      - Infrastructure Modernization
        - Introduce Azure management capabilities without migrating workloads.
