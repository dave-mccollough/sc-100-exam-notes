# Microsoft Extended Detection and Response (XDR)

- [Link](https://www.microsoft.com/en-us/security/business/security-101/what-is-xdr)
  
- Think about XDR in terms of holistic security

- Microsoft Defender is Microsoft's offical XDR Product
  - Receives data and signals from
    - Defender for Office 365
    - Defender for Identity
    - Defender for Endpoint
    - Microsoft Defender for Cloud Apps
    - Entra Identity Protection
    - Exchange online protection
    - Azure AD - On Prem
    - Endpoints/devices
    - Cloud app traffic
