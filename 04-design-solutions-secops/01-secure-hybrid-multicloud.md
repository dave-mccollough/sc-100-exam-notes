# Securing Hybrid and Multicloud Environments

- Definitions
  - Multicloud
    - Utilizing services from mulitple cloud providers 
      - ex. Some services hosted in Azure, some in AWS, etc.
  - Hybrid Cloud
    - Distributed workloads across public, private and on-prem environments
      - ex. combines on-premises infrastructure or private clouds with public cloud services

- Benefits
  - Flexibility to run your services where you want to

- Advantages of multicloud security
  - Increased reliablity
  - Constant security
  - Reduced costs
  - Centralized visibility

- Multicloud security considerations
  - Security posture of your cloud resources
    - Most secure location for your data
    - Business continuity and disaster recovery plan
    - Data loss prevention tools
  - Protect cloud and hybrid workloads against threats
    - Use cloud security solutions that provide threat prevention, threat detection, reporting and investigation functionality
  - Authentication
    - Centralize policies for authentication and authorization across cloud providers
  - Software updates
    - Ensure software updates are automated for individual cloud providers
  - Native security support
  - Centralized visibility across all infrastructure

- Types of multicloud security threats
  - No centralized management and policy enforcement
  - Deparment barriers, lack of training, team capacity limitations
  - Lack of system compatibility
  - Misconfigurations or configuration drift 
  - Not being familiar with different platforms
  - Inconsistent user permissions
  - Shadow IT
  - Poor application security practices

- Mutlicloud security best practices
  - Understand common attack strategies - choose effective security solutions that help prevent breaches
  - Use automation to streamline updates - reduce manual oversight
  - Automate defense across environments by merging threat management and response
  - Consistent security procedures to avoid complexity and human error
  - Consolidate controls for easier security management
  - Adopt principles of least privilege
  - Use cloud security posture management (CSPM) tools
  - Minimize network duplication - reduce breach points
  - Embed security in development and devops practices (DevSecOps)
