# Threat Detection with MITRE ATT&CK

- Adversarial Tactics, Techniques and Common Knowledge

- [Link](https://attack.mitre.org/)

- MITRE also created the CVE database
  - [Link](https://www.cve.org/)

- Kill Chain
  - Step-by-step model that outlines the complete structure of an attack, from the initial detection of a target to the final destruction or completion of the objective

- Reconnasissance
  - Attacker is learning about target
- Resource Development
  - Gather resources about target
- Initial Access
  - Gaining initial access to the target
    - Phishing email, code exection, etc
- Execution
  - User interacts with initial access technique
    - Click on Phishing email
    - Execute code, etc
- Persistance
  - Threat actor maintains a connection to target environment
  - Can be days, weeks, months, etc.
- Privilege Escalation
  - Threat actor will attempt to gain admin access
  - Rootkit
    - Software that compromises an OS to get higher levels of permissions
- Defense Evasion
  - Threat actor attempt to avoid defensive measures
- Credential Access
  - Getting access to higher privileges
- Discovery
  - Threat actor attempt to discover more devices they can compromise

- Microsoft has partnered with MITRE ATT&CK to display if any of the MITRE threats have occurred in your environment
