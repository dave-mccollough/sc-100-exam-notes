# Centralized Auditing and Logging

- Auditing in Microsoft Purview
- [Link](https://learn.microsoft.com/en-us/purview/audit-solutions-overview)



- Audit (Standard) Features
  - Enabled by default
  - Thousands of searchable events
  - Use the audit search tool in the Microsoft Purview compliance portal
  - `Search-UnifiedAudiLog` command from PowerShell
  - Export audit records as CSV
  - Access to logs via the Office 365 Management Activity API
  - 90 Day audit log retention
  
  - Audit (Premium) Features
    - Audit log retention policies - extend beyond the standard 90 days
    - Longer retention of audit records
    - Audit intelligent insights
    - Higher bandwidth to the Office 365 Management API

- Use Audit Manager role in Purview to access audit features

- To access Purview audit features
  - [Login to Purview](https://purview.microsoft.com/)
  - Navigate to Audit page
