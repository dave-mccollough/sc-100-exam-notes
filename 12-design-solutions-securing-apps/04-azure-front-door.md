# Azure Front Door

- [Link](https://learn.microsoft.com/en-us/azure/frontdoor/front-door-overview)

- Azure Front Door
  - Global, cloud-based Content Delivery Network (CDN) and application delivery service that improves the performance, availability, scalability, and security of web applications and APIs using Microsoft's global edge network.

- Capabilities
  - Global Load Balancing
    - Distributes application traffic across multiple regions and backend services.
  - Content Delivery Network (CDN)
    - Caches and delivers content closer to users to reduce latency.
  - Web Application Firewall (WAF)
    - Protects applications from common web attacks, malicious traffic, and bots.
  - DDoS Protection
    - Provides built-in network-layer DDoS protection and supports application-layer protection through WAF.
  - SSL/TLS Management
    - Provides secure HTTPS connections and managed certificates.
  - Intelligent Traffic Routing
    - Routes requests based on application health, priority, and latency.
  - High Availability
    - Automatically redirects traffic away from unhealthy application endpoints.
  - Monitoring & Analytics
    - Integrates with Azure Monitor for traffic analysis, logging, and security insights.
  - Private Link Integration
    - Supports private connectivity to supported backend services.
  
- Azure Front Door Tiers
  - Standard	
    - Global application delivery, CDN, load balancing, and foundational WAF capabilities
  - Premium	
    - Advanced security capabilities, including managed WAF rules and Private Link connectivity

- Use Cases
  - Global Application Delivery
    - Improve application performance for geographically distributed users.
  - Web Application Security
    - Protect internet-facing applications using WAF and DDoS protection.
  - High Availability
    - Distribute traffic across multiple Azure regions for resiliency.
  - API Acceleration
    - Improve API performance and response times.
  - Application Modernization
    - Provide global routing and security for cloud-hosted applications.
  - Content Distribution
    - Deliver static and dynamic web content efficiently.
