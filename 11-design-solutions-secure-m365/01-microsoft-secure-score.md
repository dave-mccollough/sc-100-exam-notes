# Microsoft Secure Score for M365

- [Link](https://learn.microsoft.com/en-us/defender-xdr/microsoft-secure-score)
- [Microsoft Defender XDR prerequisites](https://learn.microsoft.com/en-us/defender-xdr/prerequisites)

- Microsoft Secure Score for M365
  - A security assessment tool within Microsoft Defender that measures an organization's Microsoft 365 security posture and provides actionable recommendations to reduce risks, strengthen security controls, and improve overall protection.

- Capabilities
  - Security Posture Assessment
    - Evaluates security configurations and assigns a numerical score.
  - Security Recommendations
    - Identifies weaknesses and provides guidance for improving security.
  - Identity Protection
    - Assesses MFA, authentication policies, and identity security controls.
  - Endpoint Security
    - Evaluates device protection and endpoint security configurations.
  - Application & Data Security
    - Assesses security controls across Microsoft 365 applications and services.
  - Security Benchmarking
    - Compares security scores against similar organizations.
  - Progress Tracking
    - Monitors security improvements and historical trends.
  - Risk Management
    - Helps prioritize security improvements and document accepted risks.

- Use Cases
  - Security Assessments
    - Evaluate an organization's Microsoft 365 security posture.
  - Security Hardening
    - Identify and implement recommended security configurations.
  - Risk Reduction
    - Prioritize improvements to reduce potential security exposure.
  - Security Reporting
    - Track security improvements and report progress to leadership.
  - Compliance Support
    - Support internal security standards and compliance initiatives.

- Microsoft 365 Security Coverage
  - Secure Score includes recommendations across services such as:
    - Microsoft Entra ID
    - Microsoft Defender for Endpoint
    - Microsoft Defender for Office 365
    - Microsoft Defender for Cloud Apps
    - Microsoft Teams
    - Exchange Online
    - SharePoint Online
    - Microsoft Purview Information Protection
