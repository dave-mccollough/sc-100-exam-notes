# Microsoft 365 Secure Configuration and Operational Practices

- Implement Strong Authentication Mechanisms
  - Leverage Entra ID
  - Enable MFA
- Define Access Controls
  - Leverage RBAC
- Data Protection and Data Loss Prevention 
  - Setup DLP policies
  - Encrypt sensitive data in transit and at rest
- Secure Email Communication
  - Use Exchange online protection and Defender for Office 365
- Device Management and Security
  - Microsoft Endpoint Manager (Intune)
- Monitor and Respond to Security Incidents
  - Micrsoft Sentinel for ongoing monitoring, threat detection and response
- User Education and Awareness
