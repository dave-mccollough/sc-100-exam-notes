# Ransomware Best Practices - Backup and Restore

- Ransomware
  - Malicious software that locks or encrypts a victim's files, systems, or network
  - Demands a monetary ransom, usually paid in cryptocurrency to restore access
  - [Ransomware Protection in Azure](https://learn.microsoft.com/en-us/azure/security/fundamentals/ransomware-protection)
  - [Prepare for a Ransomware Attack](https://learn.microsoft.com/en-us/azure/security/fundamentals/ransomware-prepare)
  - Mitigation
    - Backup and restore
      - Azure Backup
    - Reduce user privileges to only what they need
      - Principles of least privilege
    - Adopt a cybersecurity framework
    - Implement Defender for Cloud
      - Links cloud and on-prem resources
    - Implement defender XDR
      - XDR - Extended Detection and Response
