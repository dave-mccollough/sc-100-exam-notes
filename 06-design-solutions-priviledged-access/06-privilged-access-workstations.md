# Privileged Access Workstations

- [Link](https://learn.microsoft.com/en-us/security/privileged-access-workstations/privileged-access-deployment)

- Privileged Access Workstations (PAWs)
  - Dedicated, highly secured devices used for performing sensitive administrative tasks. They isolate privileged activities from everyday computing, reducing the risk of credential theft, malware, and unauthorized access to critical systems.
  - PAWs create a secure environment for sensitive admin tasks
  - Seperate privileged activities from everyday operations to reduce exposure
  - Use isolated operating systems for different task levels

- Concepts
  - Secure connection to privileged endpoints
  - Foundational device security
  - Minimized attack surface
  - Risk mitigation
  - Controlled admin tasks
  - Isolation and security
  - Simplified access management
  - Flexible and secure operations
