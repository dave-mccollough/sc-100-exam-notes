# Assigning and delegating privileged roles by using the enterprise access model

- [Link](https://learn.microsoft.com/en-us/security/privileged-access-workstations/privileged-access-access-model)

- Enterprise access model
  - Privileged Access
    - Enables IT admins and other high impact roles to access senstive systems
    - Integrated into overall enterprise access control strategy

  - Control and Management Planes
    - Unified access for workloads and assets
      - Also provides threat actors a shortcut 
  - Data and Workloads
    - This model emphasizes the protection of an orgs data, applications, IP
  - User and App access   
    - How employees, partners and customers access resources
  - Zero Trust Enforcement
    - Adopts zero trust principles
      - Assuming breach
      - Validating trust explicitly
      - Granting least privilege
  - Mitigate unauthorized access
    - Prevent further unauthorized privilege escalation
  - Restricted internet access for privileged users
    - Implement network and device controls to limit outbound traffic and internet access to only essential Azure and M365 services
  - Use Defender for Cloud Apps
    - Block access to risky websites and maintain compliance
  - PIM features
    - Time based and approval based role activation
    - MFA
    - Access Reviews
    - Audit history for access to sensitive resources
