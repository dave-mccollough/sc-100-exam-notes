# Defender for Cloud

- [Link](https://learn.microsoft.com/en-us/azure/defender-for-cloud/defender-for-cloud-introduction)

- Accessed from the Azure Portal

- Microsoft Defender for Cloud is a Cloud-Native Application Protection Platform (CNAPP) that provides security posture management, threat detection, and workload protection across Azure, AWS, Google Cloud, and hybrid environments.
  - Capabilities
    - Cloud Security Posture Management (CSPM): Identifies misconfigurations, vulnerabilities, and security risks.
    - Cloud Workload Protection (CWPP): Protects virtual machines, containers, databases, storage, and applications.
    - Threat Detection: Detects suspicious activities and potential attacks against cloud workloads.
    - Secure Score: Measures security posture and provides recommendations for improvement.
    - Regulatory Compliance: Assesses cloud resources against security standards and compliance frameworks.
    - DevSecOps Security: Identifies security risks in development pipelines and infrastructure as code.
    - Multicloud Security: Provides centralized security visibility across Azure, AWS, and Google Cloud.
  - Common Use Cases
    - Cloud Security Assessment: Identify vulnerabilities and configuration weaknesses.
    - Workload Protection: Secure cloud servers, containers, and databases.
    - Compliance Monitoring: Track compliance with regulatory requirements.
    - Threat Detection: Identify and investigate cloud security threats.
    - Security Posture Improvement: Prioritize and remediate security risks.
