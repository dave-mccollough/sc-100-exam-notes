# Decentralized Identities

- [Link](https://learn.microsoft.com/en-us/entra/verified-id/decentralized-identifier-overview)

- Entra Admin Center -> Verified ID

- Microsoft Entra Verified ID
  - A decentralized identity verification service that enables organizations to issue, manage, and verify trusted digital credentials. It allows users to securely prove their identity, employment, qualifications, or other attributes without relying on traditional identity verification processes.
  - Capabilities
    - Digital Credentials: Issue cryptographically signed, tamper-evident credentials.
    - Identity Verification: Verify identities and trusted attributes using digital credentials.
    - Decentralized Identity: Allow users to control and share their credentials through digital wallets.
    - Face Check: Add biometric verification to help confirm that a credential belongs to the person presenting it.
    - Standards-Based Security: Use open standards for portable, verifiable credentials.
  - Use Cases
    - Employee Onboarding: Verify new employees' identities remotely.
    - Account Recovery: Confirm user identity when authentication methods are lost.
    - Help Desk Verification: Validate identity before sensitive support actions.
    - Employment Verification: Prove employment status without contacting HR.
    - Access Management: Verify qualifications or eligibility before granting access.
    - Partner & Contractor Verification: Validate external identities and credentials.
  
  - How It Works
    1. Issuer: An organization issues a trusted digital credential.
    2. Holder: The user stores the credential in a digital wallet, such as Microsoft Authenticator.
    3. Verifier: Another organization validates the credential's authenticity and trusted claims.
  - Security Benefits
    - Reduces identity fraud and impersonation risks.
    - Supports privacy-preserving identity verification.
    - Reduces reliance on manual identity verification.
    - Enables cryptographic verification of credentials.
    - Strengthens Zero Trust identity verification processes.
