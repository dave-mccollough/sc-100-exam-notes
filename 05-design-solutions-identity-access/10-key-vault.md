# Azure Key Vault

- [Link](https://learn.microsoft.com/en-us/azure/key-vault/general/overview)

- Azure Key Vault
  - A cloud-based service that stores and manages sensitive information like passwords, API keys, database connection strings, encryption keys, and TLS/SSL certificates.
  - Helps keep secrets out of your source code or config files.
  - You can enable monitoring on Key Vaults for activity and use monitoring
  - You can configure access policies on Key Vaults
