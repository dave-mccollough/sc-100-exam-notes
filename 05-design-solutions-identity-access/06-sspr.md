# Self Service Password Reset (SSPR)

- Entra Admin Center -> Entra ID - Password Reset
- [Link](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-sspr-howitworks?tabs=sspr)
  
  
- A feature in Microsoft Entra ID that allows users to securely reset or change their passwords without contacting IT support. Users verify their identity through configured authentication methods, reducing help desk workload and improving productivity.
