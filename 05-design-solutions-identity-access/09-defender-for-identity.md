# Defender for Identity

- [Link](https://learn.microsoft.com/en-us/defender-for-identity/what-is)
  
- Micrsoft Defender for Identity
  - Formerly Azure Advanced Threat Protection (ATP)
  - Cloud based security solution that uses on-prem Active Directory(AD) signals to identify, detect and investigate threats, compromised identities, and malicious insider actions

- Monitor and profile user activities and behaviors
  - Monitor users, entity behavior, and activities with learning based analytics
  - Protect identities and credentials stored in AD
  - Identify and investigate suspicious user activities
  - Provides clear incident information
  - Provides insights on identity configurations and security best practices
  - Reduces overall attack surface through security reports and overall and user profile analytics
  - Visual Lateral Movement Path
    - Shows how an attacker can move laterally inside your org to compromise sensitive accounts - assists in preventing those risks
  - Defender for Identity help find users and devices that authenticate using clear text passwords 
  - Provide additional guidance on how to improve org security posture 

- Active Directory Federated Services (ADFS)
  - Supports authentication in hybrid environments
  - Defender for Identity detects on-prem attacks on ADFS
  - Provides visibility into authentication events in ADFS
