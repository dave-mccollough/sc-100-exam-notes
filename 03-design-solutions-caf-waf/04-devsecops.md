# DevSecOps Process

- [Link](https://www.microsoft.com/en-us/security/business/security-101/what-is-devsecops)

- Plan and Develop
  - Threat Modeling
  - IDE Security
  - Pre-commit hooks
  - Secure coding standards
  - Peer code review
- Commit Code
  - Static application test (SAST)
  - Unit and functional tests
  - Dependancy Management
  - Secure Pipelines
- Build and Test
  - Dynamic application testing (DAST)
  - Cloud configuration validation
  - Infrastructure scanning
  - Security acceptance testing
- Promote to Production
  - Security smoke tests
  - Configuration tests
  - Live site penetration testing
- Operate
  - Continuous monitoring
  - Threat intelligence
  - Penetration Testing
  - Blameless postmortems
