# Non-relational Databases

- Non-relational Databases
  - NoSQL Database
  - Does not use the rows/columns schema
  - Uses 
    - key/value pairs
    - JSON documents
    - Graphs with edges and vertices
  - Most of these databases support SQL compatible queries

- Document Databases
  - Designed to store, manage, and retrieve data as self-contained documents (typically in JSON, BSON, or XML format) rather than in rigid, predefined relational tables.
- Columnar Databases
  - Organizes and stores database values by individual columns rather than complete rows
- Key/Value Database
  - non-relational (NoSQL) database that stores and retrieves data as a collection of unique keys and associated values,
- Graph Database
  - A NoSQL database that stores and queries data using graph theory, representing information as a network of nodes (entities), edges (relationships), and properties (key–value attributes)
- Time Series Database
  - A database optimized for storing, processing, and querying sequences of data points indexed in chronological order.
- Object Data Store
  - A computer data storage architecture that manages data as discrete units called objects rather than as a hierarchical file tree or raw blocks.
