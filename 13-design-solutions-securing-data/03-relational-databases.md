# Relational Databases

- Relational Databases
  - Store and organize data with defined relationships
  - Data is organized into tables that contain rows and columns with predefined catagories
  - Relational Databases use SQL to interact with data and the database
  - ACID Database properties
    - Atomicity
      - Defines elements that make up a complete transaction
    - Consistency
      - Defines rules for maintaining data integrity following a transaction
    - Isolation
      - Keeps the effects of transactions invisible so they don't interfere with each other
    - Durability
      - Ensures data changes become permanent after each committed transaction
