# Microsoft Intune

- [Link](https://learn.microsoft.com/en-us/intune/fundamentals/what-is-intune)

- [Intune Portal](https://intune.microsoft.com/)

- Microsoft Intune
  - Cloud-based endpoint management solution that enables organizations to manage, secure, and monitor devices, applications, and access to corporate resources across Windows, macOS, iOS, and Android.

- Key Capabilities
  - Mobile Device Management (MDM)
    - Manage and secure corporate-owned and personal devices.
  - Mobile Application Management (MAM)
    - Protect corporate applications and data, including on unmanaged devices.
  - Device Compliance
    - Enforce security requirements such as encryption, password policies, and OS version standards.
  - Endpoint Security
    - Configure antivirus, firewall, disk encryption, and endpoint protection policies.
  - Application Management
    - Deploy, configure, update, and remove applications.
  - Windows Autopilot
    - Automate Windows device provisioning and configuration.
  - Conditional Access Integration
    - Work with Microsoft Entra ID to restrict access based on device compliance.
  - Remote Device Management
    - Remotely wipe, retire, reset, or lock supported devices.
  
- Use Cases
  - Endpoint Management
    - Centrally manage laptops, desktops, and mobile devices.
  - BYOD Security
    - Protect corporate data on personally owned devices.
  - Zero Trust Enforcement
    - Require compliant devices to access corporate resources.
  - Device Provisioning
    - Streamline employee onboarding and device setup.
  - Security Compliance
    - Enforce organizational endpoint security standards.
