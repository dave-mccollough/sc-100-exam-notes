# Securing Multiple Platforms and OS's with Microsoft Defender for Endpoint

- [Link](https://learn.microsoft.com/en-us/defender-endpoint/microsoft-defender-endpoint)

- [Defender Portal](https://security.microsoft.com/)

- Microsoft Defender for Endpoint
  - Endpoint Behavioral sensors
    - Embedded in Windows
    - Collect and process behavioral signals from the OS
    - Sends sensor data to to your instance of Defender for Endpoint

    - Cloud Security Analysis
      - Behavioral signals are translated into insights, detections and recommended responses

    - Threat Intelligence
      - Generated by Micrsoft security teams and augmented by threat intelligence partners
      - Identify tools, techniques and procedures 
      - Generates alerts when data is obsevered in collected sensor data

    - Automated investigation and remediation
      - Helps reduce the volume of alerts

    - Secore Score for Devices
      - Helps assess the security state of your network
      - Identify unprotected systems
      - Provides recommended actions to improve the overall security of your org

    - Microsoft Threat Experts
      - Managed Threat Hunting Service
      - Provides proactive hunting, prioritization and context to help SOCs identify and respond to threats

- Integrates with:
  - Defender for Cloud
  - Microsoft Sentinel
  - Intune
  - Defender for Cloud Apps
  - Defender for Identity
  - Defender for Office 365
