# Microsoft Entra Global Secure Access

- [Link](https://learn.microsoft.com/en-us/entra/global-secure-access/overview-what-is-global-secure-access)

- Microsoft Entra Global Secure Access
  - Cloud-based Security Service Edge (SSE) solution that provides secure access to internet, SaaS, and private applications using Zero Trust principles, identity-based security policies, and centralized access management.

- Capabilities
  - Zero Trust Network Access (ZTNA)
    - Provides secure, identity-based access to private applications without traditional VPNs.
  - Secure Web Gateway (SWG)
    - Protects users from malicious websites, unsafe content, and internet threats.
  - Conditional Access Integration
    - Enforces access policies based on identity, device compliance, location, and risk.
  - Identity-Aware Security
    - Combines network and identity controls to enforce least-privilege access.
  - Traffic Monitoring
    - Provides visibility into network traffic, user activity, and security events.
  - Data Protection
    - Helps prevent unauthorized access and data exfiltration.
  - Unified Management
    - Centralizes network security policies within Microsoft Entra.
  
  - Core Components
    - Microsoft Entra Internet Access
      - Secures access to internet resources, Microsoft 365, and SaaS applications.
    - Microsoft Entra Private Access
      - Provides secure access to internal applications and resources without requiring traditional VPN connectivity.

- Use Cases
  - VPN Replacement
    - Provide secure remote access to corporate applications.
  - Remote Workforce Security
    - Protect employees accessing resources from any location.
  - Internet Security
    - Block malicious websites and unsafe internet traffic.
  - Zero Trust Implementation
    - Enforce identity-based access policies across applications.
  - Hybrid & Multicloud Access
    - Secure access to applications hosted on-premises and across cloud environments.
