# Security Baselines to Secure Servers and Client Endpoints

- [Link](https://learn.microsoft.com/en-us/windows/security/operating-system-security/device-management/windows-security-configuration-framework/windows-security-baselines)

- Intune > Endpoint Security > Security Baselines

- Security Baselines
  - Predefined, Microsoft-recommended security configurations designed to help organizations consistently secure devices, operating systems, and applications while reducing vulnerabilities and security risks.

- Capabilities
  - Standardized Security Configurations
    - Provide recommended security settings for Microsoft products.
  - Endpoint Hardening
    - Reduce attack surfaces by disabling or restricting insecure features.
  - Intune Integration
    - Deploy and manage security baselines across supported devices.
  - Policy Management
    - Apply consistent security configurations across an organization.
  - Compliance Monitoring
    - Identify devices that deviate from recommended security settings.
  - Baseline Customization
    - Adjust recommended configurations to meet organizational requirements.
  - Security Updates
    - Adopt updated baselines as Microsoft security recommendations evolve.

- Use Cases
  - Device Hardening
    - Secure Windows devices using recommended configurations.
  - Security Standardization
    - Establish consistent security policies across endpoints.
  - Compliance Support
    - Align endpoint configurations with organizational security requirements.
  - Risk Reduction
    - Minimize vulnerabilities caused by insecure configurations.
  - Endpoint Deployment
    - Apply security settings during device provisioning.
